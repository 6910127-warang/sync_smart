# Test Cases — FT-037 Admin ดูประวัติเหตุการณ์แจ้งเตือนทั้งหมด

> อ้างอิงจาก [Feature List](../../02-feature-list.md), [Acceptance Criteria](../acceptance-criteria.md), และ [admin-journey.md](../../03-user-journey/admin-journey.md)
>
> หมายเหตุ: ข้อมูลทดสอบเป็น placeholder ทั่วไป ไม่ใช่ข้อมูลยา NCD จริง — ดู [test-plan.md](../test-plan.md) §4 — เหตุการณ์แจ้งเตือนที่ทดสอบในไฟล์นี้ครอบคลุม 5 ประเภทที่มีอยู่แล้วในระบบ: ขอปรึกษา (FT-001/BL-003), สต็อกต่ำ (FT-011/BL-013), ก่อนกำหนดส่งคำขอเบิกประจำเดือน (FT-007/BL-009b), เบิกฉุกเฉิน (FT-006/BL-009), คอนเฟิร์มส่งออก (FT-017/BL-020) — หน้าจอนี้เป็นมุมมองการกำกับดูแล/ตรวจสอบของ Admin เท่านั้น ไม่ใช่กฎเชิงธุรกิจว่าเมื่อไหร่ต้องแจ้งเตือนอะไร (ซึ่งทดสอบแยกในไฟล์ test case ของแต่ละ Feature ต้นทางเอง)

| Test ID | Test Case Name | Pre-condition | Test Steps | Expected Result | Test Data | อ้างอิง |
|---|---|---|---|---|---|---|
| TC-171 | Admin กรองและดูประวัติเหตุการณ์แจ้งเตือนพร้อมสถานะส่งแยกช่องทาง | มีเหตุการณ์แจ้งเตือนหลายประเภทเกิดขึ้นแล้วในระบบ (เช่น ขอปรึกษา 1 รายการ, สต็อกต่ำ 1 รายการ) ในช่วงเวลาที่ทราบ | 1. Login ด้วยบัญชี Admin <br> 2. เปิดหน้าประวัติเหตุการณ์แจ้งเตือน <br> 3. กรองตามช่วงเวลาที่มีเหตุการณ์ทั้งสองรายการ <br> 4. ตรวจสอบสถานะการส่งของแต่ละช่องทางต่อเหตุการณ์ | ระบบแสดงรายการเหตุการณ์แจ้งเตือนที่ตรงเงื่อนไข พร้อมสถานะการส่งสำเร็จ/ไม่สำเร็จของแต่ละช่องทาง (อีเมล, LINE OA) แยกกันต่อเหตุการณ์ | เหตุการณ์ "ขอปรึกษา" จากหน่วยตัวอย่าง A และ "สต็อกต่ำ" ของยา A จากหน่วยตัวอย่าง B ภายในช่วงเวลาเดียวกัน | BL-049, AC Scenario 1, FR-6.12 |
| TC-172 | เหตุการณ์เดียวส่งสำเร็จช่องทางหนึ่งแต่ไม่สำเร็จอีกช่องทาง แสดงแยกกันชัดเจน | มีเหตุการณ์แจ้งเตือน 1 รายการที่ส่งอีเมลสำเร็จแต่ส่ง LINE OA ไม่สำเร็จ (เช่น จำลอง LINE OA API ล่มชั่วคราว) | 1. Login ด้วยบัญชี Admin <br> 2. เปิดหน้าประวัติเหตุการณ์แจ้งเตือน <br> 3. เปิดดูรายละเอียดเหตุการณ์นั้น | สถานะช่องทางอีเมลแสดง "สำเร็จ" และสถานะช่องทาง LINE OA แสดง "ไม่สำเร็จ" แยกกันในรายการเดียวกัน ไม่ใช่สถานะรวมเดียวที่บดบังความแตกต่างระหว่างช่องทาง | เหตุการณ์ "เบิกฉุกเฉิน" จากหน่วยตัวอย่าง C — อีเมลสำเร็จ, LINE OA ไม่สำเร็จ | BL-049, AC Scenario 2, FR-6.12 |
| TC-173 | กรองแล้วไม่พบเหตุการณ์ตรงเงื่อนไข | ไม่มีเหตุการณ์แจ้งเตือนเกิดขึ้นจริงในช่วงเวลา/ประเภทที่จะกรอง | 1. Login ด้วยบัญชี Admin <br> 2. เปิดหน้าประวัติเหตุการณ์แจ้งเตือน <br> 3. กรองตามช่วงเวลา/ประเภทเหตุการณ์ที่ไม่มีข้อมูลจริง (เช่น ช่วงเวลาก่อนระบบเริ่มใช้งาน) | **[ถือว่า]** ระบบแสดงข้อความว่าไม่พบเหตุการณ์ตรงเงื่อนไข แทนหน้าว่างเปล่าที่ไม่มีคำอธิบาย | ช่วงเวลา/ประเภทเหตุการณ์ที่ไม่มีข้อมูลอยู่จริง | BL-049, AC Scenario 3, FR-6.12 |
| TC-174 | Role อื่นที่ไม่ใช่ Admin พยายามเข้าถึงหน้าประวัติเหตุการณ์แจ้งเตือน | Login ด้วยบัญชี role อื่น (ไม่ใช่ Admin) | 1. พยายามเข้าถึงเมนู/URL หน้าประวัติเหตุการณ์แจ้งเตือนทั้งหมดของระบบ | ระบบปฏิเสธ/ไม่แสดงเมนูนี้ — เป็นมุมมองการกำกับดูแลของ Admin เท่านั้น | บัญชีเจ้าหน้าที่ รพ.สต./เภสัชกร/ผู้บริหาร | BL-049, AC Scenario 4, FR-6.12 |
