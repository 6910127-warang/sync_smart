# Test Cases — FT-018 รูปแบบไฟล์ Excel ให้ตรงกับ INVC

> อ้างอิงจาก [Feature List](../../02-feature-list.md), [Acceptance Criteria](../acceptance-criteria.md)
>
> **สถานะ (อัปเดต 20260823, รอบที่ 2):** ทั้งรูปแบบคอลัมน์ไฟล์ (BL-022) และตรรกะแยกไฟล์ 2 ชุด (BL-034) **ยืนยันแล้วครบทั้งคู่** — รูปแบบคอลัมน์จากไฟล์ตัวอย่างจริง 46 ไฟล์ และฟิลด์ `WORKING_CODE`/`HOSP_CODE`/flag "หมวดบัญชีแพทย์" เป็นฟิลด์ทางการแล้วใน [06-data-model.md](../../06-data-model.md) §3.3/§3.13 — ไม่บล็อกการทดสอบอีกต่อไป ทดสอบได้เต็มรูปแบบด้วยข้อมูลจริงทั้งหมด (TC-072, TC-101–TC-104) ไม่ต้องใช้ข้อมูลจำลองอีกต่อไป
