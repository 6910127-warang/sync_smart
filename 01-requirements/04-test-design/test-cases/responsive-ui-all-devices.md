| TC-081 | ใช้งานฟังก์ชันหลักผ่าน Desktop (1024px ขึ้นไป) | เปิดใช้งานผ่านเบราว์เซอร์บนคอมพิวเตอร์/โน้ตบุ๊กที่ความกว้างจอ 1024px ขึ้นไป | 1. เปิดระบบผ่านเบราว์เซอร์มาตรฐานที่ความกว้างหน้าต่าง 1440px <br> 2. ใช้งานฟังก์ชันหลัก (สร้างคำขอ, อนุมัติ, ดู Dashboard) ของแต่ละ role | UI แสดงผลแบบ grid 12 คอลัมน์ container สูงสุด 1440px พร้อม sidebar เมนูซ้ายคงที่ และใช้งานได้ครบถ้วน | เบราว์เซอร์มาตรฐาน ความกว้างจอ 1440px | BL-026, AC Scenario 1, NFR Usability |
| TC-082 | ใช้งานฟังก์ชันหลักผ่าน Tablet (768-1023px) | เปิดใช้งานผ่านเบราว์เซอร์/emulator บนแท็บเล็ตที่ความกว้างจอ 768-1023px | 1. ปรับความกว้างหน้าต่างเบราว์เซอร์หรือใช้ emulator เป็น 900px <br> 2. ใช้งานฟังก์ชันหลัก (สร้างคำขอ/อนุมัติ/ดู Dashboard) ของแต่ละ role <br> 3. แตะไอคอนเมนู (hamburger) ที่มุมซ้ายบน | UI ปรับเป็น grid 8 คอลัมน์, sidebar เปลี่ยนเป็น top bar + hamburger ที่เปิด drawer overlay เมนูเดียวกับ desktop และใช้งานได้ครบถ้วนเทียบเท่า desktop โดยไม่มีฟังก์ชัน/ข้อมูลถูกตัดออก | ความกว้างหน้าจอ 900px (กลางช่วง tablet) | BL-026, AC Scenario 2, NFR Usability |
| TC-083 | ใช้งานฟังก์ชันหลักผ่านมือถือ (320-767px) รวมตารางแปลงเป็น card | เปิดใช้งานผ่านเบราว์เซอร์/emulator บนมือถือที่ความกว้างจอ 320-767px | 1. ปรับความกว้างหน้าต่างเบราว์เซอร์หรือใช้ emulator เป็น 375px <br> 2. เปิดหน้าจอที่มีตาราง (เช่น ยอดคงคลัง/รายการคำขอเบิก) <br> 3. แตะไอคอนเมนู (hamburger) แล้วปิด drawer <br> 4. กดปุ่ม action หลักของหน้าจอ (เช่น "ยืนยันคำขอเบิก") | UI ปรับเป็น grid 4 คอลัมน์, เมนู hamburger + drawer ใช้งานได้เหมือน tablet, ตารางแปลงเป็น card แนวตั้งต่อแถว (label ชิดซ้าย: value ชิดขวา, ฟิลด์ครบเท่าตารางเดิม, แถบสีเตือนขอบซ้ายยังคงอยู่) แทน horizontal scroll และปุ่ม action หลัก (Primary/Danger) ขยายเต็มความกว้างของจอ | ความกว้างหน้าจอ 375px, รายการคงคลังตัวอย่าง 3 รายการ (ยา A/B/C, หน่วย รพ.สต. ตัวอย่าง) | BL-026, AC Scenario 3, NFR Usability |
| TC-100 | ความกว้างจอที่รอยต่อ breakpoint สลับ layout ถูกต้อง | เตรียม emulator/เบราว์เซอร์ที่ปรับความกว้างหน้าต่างได้แม่นยำถึงระดับ px | 1. ปรับความกว้างหน้าต่างเป็น 767px แล้วสังเกต layout <br> 2. ปรับเป็น 768px แล้วสังเกต layout <br> 3. ปรับเป็น 1023px แล้วสังเกต layout <br> 4. ปรับเป็น 1024px แล้วสังเกต layout | ที่ 767px แสดงผลแบบ mobile (grid 4 คอลัมน์, ตารางเป็น card), ที่ 768px สลับเป็น tablet (grid 8 คอลัมน์, hamburger/drawer), ที่ 1023px ยังคงเป็น tablet, ที่ 1024px สลับเป็น desktop (grid 12 คอลัมน์, sidebar คงที่) — ไม่มีองค์ประกอบตกหล่นหรือซ้อนทับผิดตำแหน่งที่รอยต่อใดๆ | ความกว้างหน้าจอ 767px / 768px / 1023px / 1024px | BL-026, AC Scenario 4, NFR Usability |
