## บริบท/ที่มา (Context)

ผู้บริหาร รพ./สสอ. ต้องการเห็นภาพรวมการกระจายยา คงคลังทั้งเครือข่าย และแนวโน้มการใช้ยา เพื่อประเมินสถานการณ์และรายงานต่อหน่วยเหนือได้

## ขอบเขต (Scope)

- **อยู่ในขอบเขต:** ภาพรวมคงคลังทั้งเครือข่าย, drill-down รายหน่วย, แนวโน้มเบิก-จ่าย, ส่งออกรายงาน, กรองตามช่วงเวลา/หน่วยงาน
- **นอกขอบเขต:** สิทธิ์การเข้าถึงโดยละเอียด (ดู [006](20260816-006-rbac-and-security-nfr.md))

## Functional Requirements

| ID | รายละเอียด |
|---|---|
| FR-3.1 | ระบบต้องแสดงภาพรวมยอดคงคลังทั้งเครือข่ายในหน้าเดียว |
| FR-3.2 | ระบบต้องแสดงแนวโน้มการเบิก-จ่ายยาแยกตามหน่วยและแยกตามรายการยา |
| FR-3.3 | **(ยืนยันแล้ว 20260823)** ระบบต้องรองรับการส่งออกรายงานเป็นไฟล์**ทั้งสองรูปแบบ: PDF และ Excel** โดยให้ผู้บริหารเลือกรูปแบบที่ต้องการได้ตอนกดส่งออกรายงานแต่ละครั้ง (ไม่ใช่รูปแบบตายตัวเพียงแบบเดียว) |
| FR-3.4 | ระบบต้องกรอง/เลือกช่วงเวลาและหน่วยงานที่ต้องการดูรายงานได้ |
| FR-3.5 | ผู้บริหารต้องสามารถ drill-down ดูรายละเอียดคำขอเบิก/ยอดคงคลังรายหน่วยได้ (ไม่ใช่แค่ภาพรวมสรุป) — สิทธิ์ read-only ทั้งเครือข่าย |

## User Stories (Agile)

- **US-3.1** ในฐานะ ผู้บริหาร ฉันต้องการเห็นภาพรวมคงคลังยาทั้งเครือข่ายในหน้าเดียว เพื่อประเมินสถานการณ์ได้อย่างรวดเร็ว

- **US-3.2** ในฐานะ ผู้บริหาร ฉันต้องการส่งออกรายงานเป็นไฟล์ PDF หรือ Excel ตามที่เลือก เพื่อนำไปใช้ประกอบการประชุม/รายงานหน่วยเหนือ
  - Acceptance Criteria:
    - [ ] Given ผู้บริหารดูรายงานที่ต้องการอยู่, When กดส่งออกและเลือกรูปแบบ "PDF", Then ได้ไฟล์ PDF ของรายงานนั้น
    - [ ] Given ผู้บริหารดูรายงานที่ต้องการอยู่, When กดส่งออกและเลือกรูปแบบ "Excel", Then ได้ไฟล์ Excel ของรายงานนั้น

- **US-3.3** ในฐานะ ผู้บริหาร ฉันต้องการ drill-down ดูรายละเอียดคำขอเบิก/ยอดคงคลังรายหน่วยได้ เพื่อตรวจสอบปัญหารายหน่วยเองได้โดยไม่ต้องกังวลเรื่องข้อมูลปฏิบัติการโดยตรง
  - Acceptance Criteria:
    - [ ] Given ผู้บริหารดู Dashboard ภาพรวม, When คลิกเลือกหน่วย รพ.สต. ใดหน่วยหนึ่ง, Then เห็นรายละเอียดคำขอเบิก/ยอดคงคลังของหน่วยนั้นแบบ read-only

## คำถามที่ถามและคำตอบที่ได้ (Clarifications)

- **ถาม:** ผู้บริหาร (รพ./สสอ.) ควรดูข้อมูลได้ระดับใดใน Dashboard? → **ตอบ:** Drill-down ดูรายละเอียดรายหน่วยได้ (ไม่ใช่แค่ภาพรวมสรุป)
- **ยืนยัน (20260823, ตอบตรงจากเภสัชกรเจ้าของระบบ ไม่ใช่การสมมติของ agent):** รูปแบบไฟล์ส่งออกรายงาน ต้องรองรับ**ทั้ง PDF และ Excel** ให้ผู้บริหารเลือกได้ตอนส่งออก ไม่ใช่รูปแบบเดียว
