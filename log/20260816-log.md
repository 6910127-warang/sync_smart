# Log — 20260816

## เปลี่ยนแปลง flow การส่งไฟล์เบิกยา: แยกบทบาท "คอนเฟิร์ม" (เภสัชกร) กับ "ดาวน์โหลด" (จนท. รพ.สต.)

- **Raw requirement ที่ได้รับ:** ต้องการให้เมื่อถึงรอบเบิก จนท. รพ.สต. กดปุ่มแล้วระบบคำนวณอัตโนมัติ ออกไฟล์ Excel ให้ดาวน์โหลดได้ และเมื่อกดคอนเฟิร์มบนหน้าจอ จะส่งไฟล์เข้าอีเมล + แจ้งเตือน LINE OA
- **การตัดสินใจ:** แก้ไขไฟล์เดิม (ไม่สร้างไฟล์ใหม่) — เนื้อหาทับซ้อนโดยตรงกับ spec 002 (FR-1.3) และ 005 (FR-4.1/FR-4.2) ที่มีอยู่แล้ว เป็นการต่อยอด/แก้รายละเอียดของ flow เดิม ไม่ใช่หัวข้อใหม่
- **ไฟล์ที่แก้ไข:**
  - `01-requirements/01-spec/20260816-002-ncd-drug-requisition-core.md` (FR-1.3, Open Items, เพิ่ม changelog section)
  - `01-requirements/01-spec/20260816-005-legacy-system-integration.md` (FR-4.1 แก้เป็นบทบาทเภสัชกร, เพิ่ม FR-4.1b สำหรับ จนท. รพ.สต., FR-4.2 resolved, US-4.1/US-4.1b/US-4.2, Clarifications, Open Items, เพิ่ม changelog section)
  - `01-requirements/backlog.md` (BL-005, BL-020, BL-020b ใหม่, BL-021 resolved, cross-epic dependency note, changelog)
- **คำถามที่ถามผู้ใช้และคำตอบ:**
  1. ขั้นตอน "กดปุ่ม→คำนวณ→Excel" เกิดตอนไหนเทียบกับ flow เดิม (สร้างคำขอ→อนุมัติ 2 ระดับ→พร้อมส่งออก→export)? → หลังอนุมัติครบ 2 ระดับ แต่เปลี่ยนคน export
  2. ไฟล์ที่ส่งอีเมล+LINE OA ส่งไปหาใคร? → ฝ่ายคลังยา รพ.แม่ข่าย (ตาม FR-4.2 เดิม) — resolved
  3. กดดาวน์โหลดกับกดคอนเฟิร์มเป็นคนเดียวกันหรือคนละขั้นตอน? → จนท. รพ.สต. ดาวน์โหลด, เภสัชกรคอนเฟิร์ม
  4. กดคอนเฟิร์มควรทำให้สถานะเป็น "จ่ายแล้ว" ทันทีหรือไม่? → ใช่ ทันที ไม่ต้องรอ INVC ยืนยันกลับ
  5. (แก้ไขกลางทาง) ลำดับที่ถูกต้องคือ: เภสัชกรคอนเฟิร์มก่อน → จนท. รพ.สต. ถึงจะดาวน์โหลดไฟล์ที่คอนเฟิร์มแล้วได้ (ไม่ใช่ดาวน์โหลดได้อิสระ)
- **Backlog items ที่เพิ่ม/แก้ไข:** BL-005 (แก้ไข), BL-020 (แก้ไข — เปลี่ยนเจ้าของ action เป็นเภสัชกร), BL-020b (เพิ่มใหม่ — จนท. รพ.สต. ดาวน์โหลด), BL-021 (resolved, รวมเข้า BL-020)
- **สิ่งที่ยังค้าง:** รูปแบบคอลัมน์ไฟล์ที่ INVC รองรับ (FR-4.3/BL-022) ยังบล็อกการพัฒนา Epic 4 อยู่; ยังไม่ยืนยันว่าเฟสนี้ต้องเชื่อมต่อ JHCIS/myPCU โดยตรงหรือไม่ (FR-4.4)
